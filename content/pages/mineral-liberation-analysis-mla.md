## Taking the guesswork out of process improvement

Mineral Liberation Analysis has been used as a metallurgical tool for analysing mineral processes for many years.

Nasaco and Betachem have three MLA units supplied by FEI. These are used for mineral liberation analysis and also for analysing process performance.

We successfully use these units to analyse reagent performance, optimise chemical usage and design reagent suites. Additionally, the units provide a superb troubleshooting tool for process optimisation.

## What an MLA report shows

Each sample scan is supplied with a software package for viewing the data, including:

- Mineral reference list
- Modal mineralogy
- Calculated assay
- Particle size distribution
- Elemental distribution
- Mineral locking
- Mineral association
- Mineral and element grade versus recovery
- Particle pictures

For examples of how this data is used to find and fix flotation losses, read [Meaningful Process Mineralogy](/meaningful-process-mineralogy/) and [Removing Gangue Minerals](/removing-gangue-minerals/).
